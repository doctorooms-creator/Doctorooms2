# ✅ PART 3 — Trademark DIY (registry-level — ye ME nahi kar sakta, captcha/OTP hai)

Web-scan meri first-pass hai. **Final pe khud ye karo (10 min, FREE):**
1. **https://tmrsearch.ipindia.gov.in/tmrpublicsearch** kholo → "Wordmark" search
2. Apna naam daalo → Search type me teeno try karo: **"Starts With"**, **"Contains"**, **"Phonetic"** (phonetic sabse important — "Sadaayu" vs "Sadayu" vs "Sadayu" spellings pakdega)
3. **Class 5 (pharma), 9 (software/app), 42 (SaaS), 44 (medical services)** — ye 4 classes check karo (hamara product sab ko touch karta hai)
4. Result "No record found" = clean. Koi "objection"/"opposed" status wala similar word dikhe = attorney se poochho
5. Shortcut tool: quickcompany.in/trademarks (free aggregate search)
6. **Final filing**: attorney through (~₹4,500-8,000 total for 2 classes with govt fee) — ya khud ipindia se (govt fee ₹4,500/class for individuals/MSME, ₹9,000/class for companies)

**Filing tip**: Jo naam final ho, TM application **jaldi** file karo — India me "first-to-file" system hai, aur filing date hi priority deti hai. Domain + TM same hafte me dono lock karo.
