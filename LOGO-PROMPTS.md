## 0. BRAND DECODE (logo se pehle dimag me ye daal lo)

| Element | Value |
|---|---|
| **Naam** | AturSeva = **atura** (अतुर — jo bimari/musibat me hai = patient) + **seva** (सेवा = selfless service) |
| **Ek line me** | *"Jo bimari me hai, uski seva"* — Ayurveda ka pehla dharma 2 morphemes me |

| **Personality** | GoI-grade **trust** + Indian **warmth** + patient-side **compassion** + modern digital product |

## 7. GEMINI ME KAISE USE KARO (step-by-step)

1. **Gemini app kholo** → latest image model select (Nano Banana / image generation ON ho) → **naya chat**
2. Master prompt (Section 4) paste → generate → **4-6 baar regenerate** (har output alag hota hai — best 2 save karo)
3. **Spelling check FIRST**: "AturSeva" 100% sahi hai? Galat = retry (AI text me common bug)
4. Pasand ka concept mil jaye → Section 6 ke lockup prompts me uska icon paragraph paste karke alag-alag pieces banwao
5. Best outputs download karo PNG me (highest resolution)
6. **Vectorize karo**: PNG → [vectorizer.ai](https://vectorizer.ai) ya Recraft → SVG (print-scale ke liye MUST)
7. Figma/Canva me final clean-up: text khud type karo (Poppins SemiBold) — AI text hata ke clean typography
8. Tests pass karao (Section 1 ke 4 tests) → final lock → **TM filing me ye artwork hi device-mark banega**

**Retry tips:**
- Text 2-3 baar kharab aaye → icon-only prompt use karo, text baad me khud add karo (yahi pro rasta hai)
- Devanagari अ distorted aaye → Concept 3 chhodo ya Figma me trace karo
